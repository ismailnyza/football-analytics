# Skill: Backtest Runner

## Use this skill when
- running the repository baseline or factor backtests
- updating validation artifacts under `docs/validation/`
- recording measured results in `infra/EVIDENCE_MATRIX.md`

## Rules
- keep evaluation chronological
- separate tuning data from the named holdout season where possible
- write the measured artifact before updating evidence ledgers
- record uncertainty and scope limits rather than overstating a single-league result
