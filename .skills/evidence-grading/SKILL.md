# Skill: Evidence Grading

## Use this skill when
- proposing a factor for the engine
- recording a backtest result
- deciding whether a claim belongs in `infra/EVIDENCE_MATRIX.md`

## Rules
- use grades A, B, C, D, F only
- do not assign a grade without a test record
- do not put Grade D or Grade F factors into runtime logic
- if a factor is disproven, record it in `infra/DISPROVEN_CEMETERY.md`
