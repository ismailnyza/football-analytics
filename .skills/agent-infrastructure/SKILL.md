# Skill: Agent Infrastructure Self-Audit

## Use this skill when
- updating prompt-adjacent docs under `infra/`
- adding or deprecating repo-local skills
- revising workflow assumptions

## Rules
- never claim a prompt improvement without recording it in `infra/PROMPT_CHANGELOG.md`
- keep `infra/SELF_AUDIT.md` current when an iteration changes the workflow
- deprecate repo-local skills only with a reason recorded in `infra/SKILL_REGISTRY.md`
- keep claims sparse and evidence-linked
