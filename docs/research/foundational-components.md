# Foundational Components Research Backlog

This note lists the first components that need research or design before the simulation engine can make truthful claims.

## Foundational components
1. Historical team-strength baseline
   - define what constitutes team strength
   - define training and holdout windows
   - define output probabilities for home win, draw, and away win
2. Backtest harness
   - fixed evaluation splits
   - reproducible seeds
   - aggregate metrics and calibration plots
3. Evidence admission path
   - factor proposal template
   - falsification criteria
   - evidence-grade assignment rules
4. Data provenance
   - source list
   - refresh cadence
   - discrepancy logging
5. Video verification workflow
   - representative match sampling
   - annotation schema
   - mechanism-check checklist

## Non-goals for the first iteration
- full player-level simulation
- speculative psychological factors
- unsupported p-values or cross-league claims
